# 交互模型（Interaction Models）第一讲：交互、XR 与具身性

## 2. 什么是交互

### 2.1 定义（Crawford, 2003）

- 参照对象始终是**人与人之间的交流**。
- **交互即对话**："两个行动者轮流**听、想、说**的循环过程。"
- **在人机交互中**："两个行动者轮流**接收输入、处理输入、产生输出**的循环过程。"

### 2.2 交流的三个层次（Rafaeli, 1988；示意图据 Bongers, 2000）

U = 用户，C = 计算机，M1…M6 = 依次发出的消息

| 类型                          | 每条新消息参照了什么                                   | 图中例子                 |
| ----------------------------- | ------------------------------------------------------ | ------------------------ |
| **双向交流（Two-way）**       | 不参照之前的消息，只是轮流发言                         | M3 与 M1、M2 无关        |
| **反应式交流（Reactive）**    | 只参照**上一条**消息                                   | C 回应 M3 时只参照 [M3]  |
| **交互式交流（Interactive）** | 参照**整个交流历史**，包括之前的消息如何参照更早的消息 | C 回应 M5 时参照 [M1…M5] |

- Rafaeli 的定义：**交互性**指的是，在一系列交流中，第三条（及以后）消息在多大程度上关联到之前的交流对更早消息的参照程度。
- 一句话：真正的交互要有**记忆**，建立在累积的上下文之上；只是"有回应"，只算反应式。

### 2.3 交互发展史上的里程碑

- **数据库系统 + 图形界面 + WIMP**（窗口、图标、菜单、指针），附 Alan Kay 的评论
- **CAD**：Ivan Sutherland 的 **Sketchpad（1963）**
- **基于头显的 VR**：建筑漫游
- **多点触控**：Jeff Han
- **媒体艺术**：_Interactive Plant Growing_，Christa Sommerer & Laurent Mignonneau
- **电子游戏**：Wii 网球

## 3. 扩展现实（eXtended Reality, XR）

### 3.1 现实—虚拟连续体（Milgram et al., 1994）

真实环境 → **增强现实（AR）** → **增强虚拟（AV）** → 虚拟环境

- Milgram 意义上的**混合现实（MR）**指两端之间的一切：真实物体和虚拟物体在同一显示中共同呈现。

### 3.2 本课程采用的实践定义

关键问题：**系统**和**用户**分别能对**数字刺激**和**物理世界**做什么？

| 类型                                          |      | 数字刺激   | 物理世界                               |
| --------------------------------------------- | ---- | ---------- | -------------------------------------- |
| **虚拟现实 VR**                               | 系统 | 生成并控制 | 不考虑                                 |
|                                               | 用户 | 与之交互   | 不考虑                                 |
| **增强虚拟 AV**（把物理世界叠加到数字刺激上） | 系统 | 生成并控制 | 能**检测**其中的元素，但无法影响       |
|                                               | 用户 | 与之交互   | 可以**借助物理世界**与数字刺激交互     |
| **增强现实 AR**（把数字刺激叠加到物理世界上） | 系统 | 生成并控制 | 用来**调整**数字刺激，但无法控制或影响 |
|                                               | 用户 | 与之交互   | 能**感知**，但不能交互                 |
| **混合现实 MR**（两者同等重要地混合）         | 系统 | 生成并控制 | 能**感知并控制**                       |
|                                               | 用户 | 与之交互   | 与之交互                               |

- ⚠️ **VR 不限于头显！** 只有数字刺激的投影式体验同样是 VR。
- 课程立场：理论上有四类，实践中边界模糊，所以统称为 **XR**。

### 3.3 课堂练习：给应用分类

| 应用                                                        | 分类                      | 理由                                                         |
| ----------------------------------------------------------- | ------------------------- | ------------------------------------------------------------ |
| **Funky Forest**（Design I/O）                              | 增强虚拟 AV               | 系统检测孩子的身体和实物，把它们当作输入，但无法改变它们     |
| **腹腔镜手术模拟器**（MedVision）                           | VR / AV（两张表都给出了） | 场景完全是数字的，但通过系统追踪的真实手术器械来操作         |
| **Messa di Voce**（Golan Levin & Zachary Lieberman）        | 虚拟现实 VR               | 声音驱动投影图形，物理世界不属于内容的一部分。说明 VR ≠ 头显 |
| **AR 魔法灯笼**，Barcino（古罗马时期的巴塞罗那），FuBIntLab | 增强现实 AR               | 数字复原根据真实遗址调整，但用户不能与遗址本身交互           |
| **Puppet Parade**（Design I/O），仅指操控手偶的用户         | 虚拟现实 VR               | 手部操控者只控制数字木偶                                     |
| **Kobito 虚拟小精灵**（东京工业大学）                       | 混合现实 MR               | 虚拟小人推动**真实的**茶叶罐；系统既感知又**影响**物理世界   |

_腹腔镜模拟器那页同时放了 VR 和 AV 两张表，可能是留作讨论。理由一栏是我根据课件做的解读。_

## 4. 交互模型与交流

### 4.1 课程核心问题

如何向用户解释 XR 体验中的**中介（mediation）**？→ **虚拟主体性（Virtual Subjectiveness, VS）**（Parés & Parés, 2001；S3 前阅读）。

### 4.2 交流理论

- **香农通信模型**：信源 → 发送器 → 信道（噪声）→ 接收器 → 信宿。描述的是**传输**。
- **Terry Winograd（2006）**："交流成功与否取决于听者真正的智能。"**交互建立在交流之上。**
- **翁贝托·艾柯（1976）**：在符号学中，**只有发生了诠释，才算交流**。
  - **传递过程**：信号从发送者传到接收者，内容不变，不考虑其意义。
  - **交流过程**：信号**要求接收者做出诠释性回应**。
- **设计启示**：要仔细评估用户在交互中如何**建构意义**，以及事后如何**诠释**这段体验。
- **Winograd 谈人机交互**："没有一种媒介适合所有事情。"
- **麦克卢汉（1967）**："我们透过后视镜看现在，倒退着走向未来。"新媒介最初总是借旧媒介来理解。

## 5. 具身认知与具身交互

### 5.1 具身认知关注什么

- 我们如何感知世界
- 我们如何把经验概念化
- 我们如何建立世界的模型
- 身体如何"介入"认知过程，也就是身体如何**中介**我们对世界的理解

### 5.2 从笛卡尔二元论到"活的身体"

- **笛卡尔二元论**：身心分离，意识是知识的来源。
- **梅洛-庞蒂（1940 年代）**质疑二元论，把身体重新引入，视为帮助建构知识的**熟练主体性**："**身体是我们拥有一个世界的总体媒介。**"
- **当代观点**：每个人都是一个**"活的身体（lived body）"**，身体在心智与世界之间起**中介**作用。
- 相关领域：生理学、现象学、知觉生态学、发展心理学（建构主义、建造主义）、具身隐喻、活动理论、情境认知。

### 5.3 关键学者

| 领域                   | 学者                      | 核心观点                                                                          |
| ---------------------- | ------------------------- | --------------------------------------------------------------------------------- |
| 哲学                   | **梅洛-庞蒂**             | 每个人都是一个"活的身体"                                                          |
| 心理学                 | **J. J. Gibson**          | 身体影响人的理解                                                                  |
| 社会心理学             | **Barsalou & Niedenthal** | 实验表明知识是**扎根**于身体状态和大脑特定感觉通道系统中的                        |
| 认知科学               | **Barsalou**              | 大脑中运动区与认知加工之间存在结构联系                                            |
| 神经生理学             | **Gallese**               | **镜像神经元**参与对交流性动作的感知、模仿、基本的心理推测和共情                  |
| 认知语言学             | **Lakoff & Johnson**      | **具身隐喻理论**：抽象概念和概念隐喻建立在源于身体动作的**意象图式**之上          |
| 发展心理学             | **皮亚杰**                | 人从**主动经验**中建构知识                                                        |
| 发展心理学             | **维果茨基**              | 发生在物理和社会世界中的人际心理过程，是发展个体内部心理过程的必要条件 → **内化** |
| 哲学、生物学、神经科学 | **Varela 等**             | 关于世界的知识无法与我们**在世界中的立足点**分开                                  |

### 5.4 Gibson：生态知觉与可供性（1979）

- **环境光阵（ambient optic array）**：感知是对环境的**主动探索**；知觉系统是在**移动中的**生物体里进化出来的。
- **可供性（affordance）**：所有"行动可能性"都潜藏在环境中，可以客观测量，与个体是否意识到无关，但始终**相对于某个行动者**及其能力而言。
- 影响方向：环境 → 生物体。身体塑造理解。

### 5.5 Dourish（2001）《行动之所在》（_Where the Action Is_）

- **现象学**：
  - 思考与存在、行动不是分开发生的。
  - 感知始于**实际经验到的东西**，而不是预期的东西。
  - 关键概念：**感知与行动**。
- **具身性**：
  - 基于我们如何体验日常世界：我们能理解环境，是因为我们有一个能作用于环境的身体。
  - 具身性关乎**行动与意义之间的关系**。
  - **具身性 ≠ 物理现实。**
  - 它具有**参与性**：事物嵌入在世界中，它们的现实性取决于这种嵌入；我们是世界和社会不可分割的一部分。
- **具身交互**：
  - 交互与它发生的情境相关联 → **情境化视角**。
  - 没有抽象的用户或场景：**真实的用户，在真实的场景中，做真实的事**。
  - 具身交互 = **可触计算 + 社会计算**（既包括物理实物，也包括社会互动）。

### 5.6 具身认知的三个领域

| 关系                      | 方面                                     |
| ------------------------- | ---------------------------------------- |
| **与自身身体**            | 本体感觉、动觉、手势                     |
| **与空间**（身体 ↔ 空间） | 导航、视角、尺度与比例等                 |
| **社会关系**（人 ↔ 人）   | 面对面互动、非言语交流、面部表情、情绪等 |
