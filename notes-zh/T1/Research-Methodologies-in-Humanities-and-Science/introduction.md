# 研究方法

## 第一讲 导论 · 现实与共识（Reality and Consensus）

### 1.1 什么是研究

- **弗拉斯卡蒂手册（OECD, 2015）**：研究与试验发展（R&D）是**有系统地开展的创造性工作**，目的是增加知识存量（包括关于人、文化和社会的知识），并利用这些知识开发新应用。
- **R&D 的三种类型**

  | 类型                                 | 目标                                                 | 是否有应用目标       |
  | ------------------------------------ | ---------------------------------------------------- | -------------------- |
  | 基础研究（Basic）                    | 获取关于现象底层原理的新知识                         | 无                   |
  | 应用研究（Applied）                  | 获取新知识                                           | 有，指向具体实践目标 |
  | 试验发展（Experimental development） | 利用已有知识开发新产品、流程、系统，或显著改进已有的 | 有                   |

- **Rashid（微软研究院，2006）**：先进产品开发**不是**研究。研究必须能在同行评审的会议或期刊上发表，经得起本领域顶尖学者的检验。
- **人文学科的视角**：研究不只是发现未知，也包括从批判或创造的角度**重新诠释或重新发现已知事物**（文本、文化产品）。研究的根本在于**创造新东西**，可以是艺术创作，也可以是学术分析。
- **Oates（2006）**：好的研究不急于下结论，要做到：
  - 找到充分且恰当的数据来源
  - 规范地记录、分析和解释数据
  - 依据证据得出有根据的结论
  - 以可接受的形式呈现（报告、论文、学位论文）
- 研究是创造新知识，并且要**让研究的使用者满意**。

### 1.2 研究者做什么

- 构建并**捍卫一个论点**，证明自己确实创造了新知识（建立在他人工作之上）
- 寻找新的抽象、方法、算法、原理、机制
- **选择适合研究问题的方法和活动**
- 准备好使用**多种方法和工具**（不同项目、同一项目的不同阶段都会变化）
- 即使问题本身还不明确，也在寻找答案

### 1.3 研究的两个重要特征

- **严谨（Rigorous）**：过程系统、有效、恰当
- **相关（Relevant）**：对某个人、社会或学术共同体有意义

### 1.4 博士学位（PhD）

- 最高学位：精通一个领域，并**扩展该领域的知识体系**
- 出路：工业界或研究机构的研究岗位、学术职位

### 1.5 真理与可信度（Bruckman, 2005）

- 科学社会学认为**真理是社会建构的**：一个人或小团体先提出假设，接受的人越来越多，它就逐渐被当作"事实"。
- 即使是客观主义者也必须承认：某件事**被接受为事实的过程**是社会性的。
- **同行评审 = 制造事实这一过程的制度化。**
- **可信度四问**（面对任何信息都要问）：
  1. 谁提出的？
  2. 这个人有什么资历？
  3. 谁有机会批评这个观点？
  4. 谁支持，谁反对？
- 非正式的网络发布也可能有一定可信度，取决于来源和他人的回应。看起来像正式文章、但发布在推行激进议程的组织网站上的内容，可能毫无可信度。
- 科学的标准是：**"我们相信这个，因为这些同行评审的文献支持它。"**

### 1.6 库恩（Kuhn, 1970）：范式与科学革命

- **范式（Paradigm）**：一套假设、概念、价值和实践，构成一种被接受的看待现实的方式，**在一段时期内**被视为真。它本质上仍只是**科学共同体**内部的共识。
- **范式如何形成**：收集"单纯的事实" → 前范式阶段各学派竞争 → 某一范式的力量和支持者不断增加 → **使一个团体成为一门学科**（有专门期刊、学会）→ 学生学习范式，从而加入该共同体。
- **科学革命**：发现**反常（anomaly）**，即违背范式预期的现象 → 专业共同体对共同假设的承诺发生转变。例子：行星运动定律（哥白尼、开普勒、牛顿）。

### 1.7 科学是协商出来的（Tedre et al., 2006）

- 决策也受经济、政治、意识形态和文化动机影响：
  - GNU/Linux：技术、经济、意识形态动机共同作用
  - OS/2 输给 Windows 95，原因不在技术
- ICT 领域是跨学科的，同时向多个范式开放（如 ACM 各专委会）。

### 1.8 学术不端与伦理

- **欺诈**（不可复现）vs **研究偏差**（只能在狭窄条件下复现）
- **捏造 / 篡改**：隐瞒不支持自己观点的数据，操纵数据以呈现想要的结论
- **剽窃**：把他人成果当作自己的，既欺骗读者，也剥夺原作者应得的认可
- 讨论点：**自我剽窃**；**合法 ≠ 合乎伦理**（研究可以合法但不合伦理）
- 案例：黄禹锡（Woo Suk Hwang），2006 年克隆人类胚胎干细胞数据造假

## 第二讲 信息来源（Information Sources）

### 2.1 记录文献

要记下：

1. 内容的简要摘要
2. **你自己的评价**
3. 完整的文献信息，方便读者找到原文

工具：过去用卡片（艾柯《如何写论文》），现在用文献管理软件。软件可以检索笔记，还能把引用直接插入文字处理软件。

### 2.2 写作时如何引用

- 文献综述要围绕**自己的研究课题和目标**展开。
- 从领域内的总体概念讲起，逐步收窄到自己的研究问题。
- **按概念组织，优于按作者罗列。**
  - 按作者："X（年份）发现了 A，Y（年份）发现了 B……"
  - 按概念（推荐）："A 的证据见于（X, 年份；Z, 年份）……"

### 2.3 引用格式

- **作者-年份制**：正文中写作者和年份，参考文献按作者字母排序
- **编号制**：正文中写编号，参考文献按编号排序
- 具体格式由各期刊或会议规定。

### 2.4 十类信息来源

| #   | 来源              | 特点         | 优点                   | 缺点                       | 注意       |
| --- | ----------------- | ------------ | ---------------------- | -------------------------- | ---------- |
| 1   | 报纸文章          | 及时         | 覆盖面广               | 不深入                     | 查作者     |
| 2   | 杂志文章          | 流行         | 聚焦                   | 覆盖有限                   | 查编委会   |
| 3   | 书籍              | 全面         | 有深度                 | 受限于特定时间、地点、作者 | 查作者     |
| 4   | 手册              | 实用         | 描述详细               | 未经评审                   | 查错误     |
| 5   | 报告              | 吸引人       | 呈现的问题多于方案     | 不客观                     | 查概念错误 |
| 6   | 预印本 / 进展报告 | 及时         | 与自己的研究同步       | 不可靠                     | 查各类错误 |
| 7   | 会议论文集        | 反映领域现状 | 多样                   | 质量参差                   | 查质量     |
| 8   | 同行评审期刊      | 学术性       | 权威                   | 滞后一到两年               | —          |
| 9   | 同行评审综述      | 学术性       | 权威且全面             | 范围有限                   | —          |
| 10  | 人                | 无所不包     | 文字难以承载的深层知识 | 难找                       | —          |

### 2.5 各类来源的用途

- 报纸、杂志 → 了解相关学科的重大变化
- 报告 → 了解来自产业界和社会的问题与需求
- 书籍 → 学习有吸引力的观点
- 会议论文 → 追踪研究共同体的**趋势**
- 同行评审期刊 → 作为自己研究的**基础**
- 手册 → 日常工作
- 综述 → **开启新的研究方向**

如何用好信息需要时间，是随着判断力的积累逐渐掌握的。

## 第三讲 研究方法概览（Research Methods Overview）

### 3.1 科学方法

没有一种普遍适用的唯一方法，但通常包括：

1. 界定问题
2. 收集背景信息
3. 提出假设
4. 观察
5. 检验假设
6. 得出结论
7. 报告结果

### 3.2 相关方法（Zelkowitz & Wallace, 1998）

- **科学法**：提出理论 → 提出假设 → 检验假设的不同变体 → 用数据证实或证伪
- **工程法**：开发并测试一个方案 → 不断改进，直到无需再改进
- **实证法**：用统计方法验证假设，可以没有正式的理论模型
- **分析法**：建立形式理论 → 将推导出的结果与观察对比
- 领域特有方法：**设计科学研究**（信息系统）、**基于设计的研究**（教育）

### 3.3 研究的整体流程

研究动机与预期成果、个人经验与动机、**文献综述**三者共同导出**研究问题** → 研究方法（理论或实验）。文献综述同时构建**研究背景 / 概念框架**。

### 3.4 研究的答案可以是什么

**理论、定律、模型或方法**，或对其中之一的改进。

- **假设（Hypothesis）**：基于少量观察、没有实验证据的有根据的猜测
- **理论（Theory）**：基于大量观察和大量实验证据；可以用于新的关系；有新证据时可以修正。理论是**解释**。
- **定律（Law）**：经受了时间检验，反复被实验证实；能在不同情境中做出正确预测；具有普遍性。定律是**概括或规律**。
- **所有科学知识都是暂定的**，定律也一样。科学上的"证明"不同于数学证明，这种暂定性正是科学自我纠错的一部分。
- **模型（Model）**：一个可检验的想法，解释世界某部分如何运作，并能预测类似情境；**只在有限情境下准确**。好模型要尽量多地解释观察到的特征，同时尽量简单。
- **奥卡姆剃刀**（_Pluralitas non est ponenda sine necessitate_，如无必要，勿增实体）：两个模型预测效果相同时，选更简单、假设更少的那个。
- **方法（Method）**：新的或改进的流程，基于理论、定律或模型，或者从一个需要实验检验的假设推导而来。

### 3.5 归纳、演绎、溯因

| 推理方式          | 方向                                | 能否保证结论为真       | 用途                       |
| ----------------- | ----------------------------------- | ---------------------- | -------------------------- |
| 演绎（Deduction） | 从前提推出必然结论（B 是 A 的结果） | 能，前提为真则结论必真 | 检验定律（先预测，再检验） |
| 归纳（Induction） | 从多个实例概括出一般规律            | 不能                   | 从积累的事实中提出定律     |
| 溯因（Abduction） | 从事实推出最佳解释（B 解释 A）      | 不能                   | **生成假设**，需要创造力   |

- 三段论：所有人都会死；苏格拉底是人 → 苏格拉底会死。
- 黑公牛例子：每发现一头黑公牛，都只是**支持**"所有公牛都是黑的"，不能证明它；发现一头白公牛就会使它受到质疑。
- 培根式知识生产循环：证据 → 归纳 → 定律 → 演绎 → 证据……
- 面对同样的证据，科学家**不会**都得出相同的结论。**创造力至关重要，尤其在溯因中。**

### 3.6 实验并不简单

空泛的说法不是证据："这个技术很有效"、"它能用"、"结果是积极的"、"我试过，我喜欢"。必须有**测量**有效性的方法。

### 3.7 实验验证方法（ICT 领域）

**观察型**：在项目进行中收集数据

| 方法     | 描述                                           | 弱点                     | 优点                   |
| -------- | ---------------------------------------------- | ------------------------ | ---------------------- |
| 项目监测 | 在项目中被动收集数据                           | 没有具体目标             | 提供基线，便宜         |
| 案例研究 | 深入、有目标、主动地研究一个案例，获得丰富洞察 | 难以复现，难以做统计推广 | 成本低，可控制一个因素 |
| 断言     | 开发者既是实验者又是被试                       | 有偏差                   | 可作初步检验           |
| 实地研究 | 监测多个项目，侵入性较低                       | 各项目条件不同           | 低成本的复制           |

变体：**民族志**（研究者参与所研究群体的生活）、**问卷调查**（从大量人群标准化地收集数据）。

**历史型**：从已完成的项目收集数据

| 方法     | 描述                                       | 弱点                                               | 优点                 |
| -------- | ------------------------------------------ | -------------------------------------------------- | -------------------- |
| 文献检索 | 研究已发表的研究                           | **选择偏差**（正面结果更容易发表）；各研究条件不同 | 资料多，便宜         |
| 遗留数据 | 分析过往项目的定量数据和产物（"数据挖掘"） | 无法控制变量                                       | 可合并多个研究，便宜 |
| 经验教训 | 分析过往项目的定性数据                     | 没有定量数据                                       | 能看出趋势           |
| 静态分析 | 分析产品结构以确定其特征                   | 指标未必反映目标属性（代码行数 ≠ 复杂度）          | 可自动化             |

**控制型**：多次观察，保证统计效度

| 方法         | 描述                                     | 弱点                                           | 优点                       |
| ------------ | ---------------------------------------- | ---------------------------------------------- | -------------------------- |
| 重复实验     | 做多个版本，实验组对比对照组             | 非常昂贵；**霍桑效应**                         | 能控制所有因素，统计效度高 |
| 合成环境实验 | 实验室环境，只改变一个因素，随机分配被试 | 难以扩大规模，难以反映真实环境中因素的相互作用 | 能控制单个因素，成本适中   |
| 动态分析     | 运行产品进行测试（如基准测试）           | 难以推广到其他数据集                           | 可自动化                   |
| 模拟         | 在真实环境的模型中运行产品               | 不确定模型与现实有多接近                       | 安全、快速、便宜           |

### 3.8 实验术语

- **因素（Factor）**：要研究其效果的方法或工具
- **处理（Treatment）**：因素的一种具体设定
- **被试 / 实验单元（Subject）**：收集数据的对象
- 目标：每种处理有足够多的被试，以便进行**统计显著**的比较
- **可复现（Replication）**：让其他研究者能复现结果；使用同质样本，或者随机化
- **局部控制（Local control）**：**区组设计**（如同质的学生群体）；**析因设计**（所有处理组合都做）
  - 注意：课件说 3 个因素 × 各 3 个取值 = 9 组实验，但**完全析因设计**需要 3³ = **27** 组。

### 3.9 数据

- **收集工具**：访谈、观察、问卷、文档（包括多媒体）、日志文件、生理数据
- **定量分析**：用统计说明变量间的关系不是偶然的；能显示趋势和概率，但**不能预测单个个体**
- **定性分析**：在人们的言语或图像中寻找主题和类别；结论**只能推广到所研究的对象和情境**
- **三角验证（Triangulation）**：用多种工具相互印证，提高效度。
  - 类型：方法、**时间**、**空间**（不同国家或文化）、**研究者**
  - 例：用户在访谈中说网站好用，但日志显示他们频繁打开帮助页。

## 第四讲 研究的写作与展示（Writing and Presenting）

### 4.1 总体原则

- **清晰简洁**；**前后一致**（记号、格式、人称：被动语态 vs 第一人称）
- 研究论文 vs 综述论文。研究论文中的"相关工作"部分相当于一个小综述。
- 研究论文 = **问题 → 提出的方案 → 结果**
- 重点写清：
  - **有效性**：细节足以证明结果成立
  - **新颖性**：报告了什么新知识，为什么它不是显而易见的
  - **意义**：结果意味着什么改进或影响

### 4.2 论文结构

- **标题**：简洁具体，避免 "novel"、"performance evaluation"、"contribution" 这类词
- **作者**：须同时满足三条：
  1. 有实质性的智力贡献
  2. 参与撰写或在内容上修改
  3. 批准最终版本
- **摘要**：问题、方案、结论；约 150 词以内；不写一般性动机、公式和引用
- **关键词**：为计算机检索而选
- **引言**：动机和重要性 → 相关工作（要引用）→ 简述方案及其优势 → 最后一段介绍文章结构（"The remainder of the paper is organised as follows…"）
- **正文**：系统模型（写清假设，配图）→ 架构（比自己的实现更通用）→ 实现
- **数值结果**：用图表；**要解释**（是假设造成的，还是系统本身如此？）；给出置信区间；细节足以让读者**复现**
- **结论**：总结、**局限性**、**未来工作**；不引入新概念
- **参考文献**：引用最容易获取的版本（有期刊版就引期刊版）；尽量避免内部报告、私人通信、预印本
- **附录**：理解论文不必需、但为完整性而附上的材料（证明、协议、问卷）
- **图表**：在正文中被引用；脱离正文也能读懂；清晰可辨
- **致谢**：资助来源（项目编号、规定措辞）和同事的帮助

### 4.3 版本管理（VERSIONS toolkit, 2008）

记录各个里程碑版本：草稿 → 投稿版 → 录用版 → 校样 → 出版版。

### 4.4 口头报告

- 排练并计时（大约每页 1–3 分钟）；请同事旁听、提问
- 提前去看场地
- 开投影前先和观众说几句：主题、与本场其他报告的联系、你是怎么对这个题目产生兴趣的
- 保持眼神交流；视觉材料清晰可读；每页不要放太多想法；页面上的东西都要讲到；少放数学，多用图
- 目标：讲清**工作为什么重要、核心思路、与现有方案有何不同或更好之处**
- 准备一页 **"Contributions"（贡献）**
- 答问：不要防御。难题可以转为未来工作，或者留到茶歇时再讨论。

### 4.5 海报、演示、答辩

- **海报**：确认尺寸；写标题和联系方式；醒目；多用图少用字。数字艺术展通常附一段反思性文字。
- **软件演示**：在实际使用的机器上测试（包括电池）；提前到场；按逻辑顺序展示。出故障时道歉，转到其他部分，并说明程序本该如何运行。
- **论文答辩**：委员会看
  1. 对问题和文献的深入理解
  2. 贡献
  3. 是否真正消化了结果（能解释看起来奇怪的结果）
  4. 未来工作方向
