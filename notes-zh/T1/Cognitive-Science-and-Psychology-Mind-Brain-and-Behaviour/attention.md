# 注意（空间注意与忽视症）复习笔记

## 1. Posner 的注意模型：三个注意网络

| 网络                      | 定义                                         | 主要脑结构                                       | 神经调质         |
| ------------------------- | -------------------------------------------- | ------------------------------------------------ | ---------------- |
| **警觉（Alerting）**      | 达到并维持对输入刺激的**高敏感状态**         | 蓝斑、右侧额叶和顶叶皮层                         | **去甲肾上腺素** |
| **定向（Orienting）**     | 从感觉输入中**选择**信息                     | 顶上叶、颞顶联合区、额叶眼区、上丘（以及丘脑枕） | **乙酰胆碱**     |
| **执行注意（Executive）** | **监控并解决**思维、情绪和反应之间的**冲突** | 前扣带回、腹外侧前额叶、基底节                   | **多巴胺**       |

_脑结构和神经调质来自课件中的表格和脑图（Posner & Rothbart 的总结）。_

- 执行网络和下一讲（执行脑：flanker、Stroop 任务）衔接。
- **《威利在哪里？》**是演示定向和视觉搜索的例子。

## 2. 定向网络：Posner 线索任务（Posner & Cohen）

### 2.1 实验设计

- 注视屏幕中央。先出现一个**线索**（箭头，或某个位置闪一下），然后出现**目标**，被试尽快反应。

| 试次类型     | 含义                     | 出现比例                 |
| ------------ | ------------------------ | ------------------------ |
| **有效线索** | 目标出现在线索指向的位置 | **75–80%**               |
| **中性线索** | 线索不指向任何位置       | 20–25%（中性和无效合计） |
| **无效线索** | 目标出现在**另一侧**     |                          |

### 2.2 结果

- 反应时（从课件曲线图上读出的近似值）：**有效 ≈ 320 ms < 中性 ≈ 355 ms < 无效 ≈ 380 ms**。
  - **收益** = 中性 − 有效（注意已经在正确的位置）
  - **代价** = 无效 − 中性（注意要先**脱离、移动、再重新锁定**）
- 注意可以在**眼睛不动**的情况下移动（隐蔽定向）。

### 2.3 返回抑制（Inhibition of Return, IOR）

- 某个位置被注意之后：
  - 在约 **100–300 ms** 内，那里的检测**更快、更准**
  - 之后约 **500–3000 ms** 内，那里的检测反而**变慢、变差**
- 课件的曲线以 **CTOA**（线索与目标出现的时间间隔）为横轴：
  - CTOA 短时，**有效**试次更快
  - CTOA 较长时（大约从 200–300 ms 起），结果**反转**，线索位置反而更慢
- **作用**：在视觉搜索中，返回抑制阻止注意回到已经看过的地方，从而**鼓励探索新的、还没注意过的物体**。

## 3. 两条视觉通路

- **背侧通路（"在哪里"）**：枕叶 → **顶叶**。负责空间加工：位置、运动、空间变换、空间关系。
- **腹侧通路（"是什么"）**：枕叶 → **颞叶**。负责物体加工：颜色、纹理、细节、形状、大小。
- **偏侧空间忽视**源于**背侧 / 顶叶**受损，典型的是**右侧顶叶**（见课件中的脑扫描图）。腹侧通路受损则导致**视觉失认症**这类问题（课件最后一个视频）。

## 4. 偏侧空间忽视（Hemispatial neglect）

### 4.1 是什么

- 右半球（常见于右侧顶叶）受损后，病人会**忽略左侧空间**：只吃盘子右半边的食物，只刮右半边脸，常撞到左边的东西。
- 他们的视觉本身可能完好，问题出在**对一侧的注意**。

### 4.2 知觉演示

- **"哪根条看起来更暗？"** 两根互为镜像的灰度渐变条，整体亮度其实完全一样。
- **"哪个刻度更大？"** 两个互为镜像的黑色楔形。
- _这是灰度任务和楔形刻度任务（我的补充，课件只给了图和问题）：_
  - **健康人**有轻微的**左偏**（假性忽视）：会选深色端或宽端在**左边**的那个。
  - **忽视症病人**则有明显的**右偏**。

### 4.3 经典临床测验

| 测验                              | 病人的表现                                                                                 |
| --------------------------------- | ------------------------------------------------------------------------------------------ |
| **划线删除（Line cancellation）** | 只划掉纸面**右侧**的线段                                                                   |
| **线段二等分（Line bisection）**  | 标出的"中点"**偏右**，因为线段左边那部分没被纳入考虑                                       |
| **读词**                          | 把 **COWBOY** 读成"**BOY**"（漏掉左半边）                                                  |
| **临摹图画**                      | 只画出**右半边**：花只有一侧有花瓣，钟面的数字全挤在右边，房子缺左半部分，风景缺左边的东西 |

### 4.4 心理表象的忽视：Bisiach & Luzzatti（1978）

- 让米兰的病人凭记忆想象并描述**米兰大教堂广场**。
  - 想象自己**面对大教堂**时，只说出了想象中**右侧**的建筑。
  - 想象自己**站在广场另一端**时，说出了之前**漏掉**的那些建筑，而新的左侧又被漏掉了。
- 说明信息**存储在记忆里**，被忽视的是**心理表象的左侧**（表象性忽视）。
- 课件用**巴塞罗那加泰罗尼亚广场**作为同一任务的本地版本。

### 4.5 内隐加工："是注意缺陷，不是知觉缺陷"

**消退现象（Extinction）**

- 左边单独出现青蛙 → "我看到一只青蛙"；右边单独出现太阳 → "我看到太阳"。
- **两个同时出现** → "我看到一个太阳"，左边的青蛙**没有被报告**。
- 左侧刺激单独出现时能被知觉，但右侧有竞争刺激时，它就在**注意的竞争中输了**。

**着火的房子（Marshall & Halligan, 1988）**

- 给病人看两张房子的图，其中一张房子**左侧在着火**。
- 她说两栋房子**一模一样**，但问她更愿意住哪一栋时，她**选了没着火的那栋**。
- 那团"没看见"的火**影响了她的选择**。

**语义分类启动任务**

- 任务：判断注视点**右边**的图是水果还是动物。
- 在它出现前 **200 ms**，**左边**会先出现一张图（呈现 200 ms）。**5 名病人都斩钉截铁地否认**出现过两张图。
- 三种条件：**高度一致（HC**，如同一张图）、**一致（C**，同一类别）、**不一致（NC**，不同类别）。
- 反应时：**HC ≈ 740 ms < C ≈ 750 ms < NC ≈ 850 ms**。
- 没被"看见"的左侧图片**启动**了反应：它被加工到了**语义层面**，只是没有进入意识。
- _这是 Berti & Rizzolatti（1992）的经典范式，课件没有注明出处。_

**结论**：忽视症是**注意 / 觉知**的缺陷，而不是知觉的缺陷。被忽视的信息仍然会被加工，有时甚至加工到意义层面。

### 4.6 康复（视频）

- 训练病人主动向左侧扫视，例如视觉扫描训练、在左侧设置提示标记。_视频的具体内容课件上没有。_
