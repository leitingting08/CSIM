# 语言心智（The Linguistic Mind）

## 1. 什么是语言？

- 开篇两张图：罐子里的大脑，以及诺贝尔物理学奖得主 Donna Strickland 的一句话（"不是每个人都觉得物理有趣，但我觉得"，啁啾脉冲放大，2018）。语言让一个心智中的想法抵达另一个心智。
- **形式层面**：所有语言使用同一类"元素"。
  - 所有语言都有主语、动词、宾语。
  - 所有语言都会把元素组合起来。

### 1.1 人类语言的核心属性

| 属性                                 | 含义                                                           |
| ------------------------------------ | -------------------------------------------------------------- |
| **生成性（Generative）**             | 用有限的部件表达无限多的想法                                   |
| **递归性（Recursive）**              | 可以无限地自我嵌套（结构里套结构）                             |
| **移位性（Displacement）**           | 能谈论不在眼前的事物（过去、未来、不在场的、想象的）           |
| **模态独立（Modality-independent）** | 以上属性在任何模态中都成立：口语是听觉形式，**手语**是视觉形式 |

### 1.2 多样性

- 每种语言都是对同一个问题的**一种特定解法**。
- 语言有**不同层级**，呈**层级化组织**（"洋葱图"，由内到外）：

  语音 → 音系 → 形态 → 词 → 句法 → 语义 → 语用 / 语篇

## 2. 语言的各个层级与跨语言例子

### 2.1 语音学（Phonetics）：声音本身

- 英语 *th*is（/ð/）vs 西班牙语 da*d*o：听起来相似，发音方式不同。
- **声调**：在汉语里，**音高**决定词义。
- **科萨语（Xhosa）**用**搭嘴音（click）**作辅音。

### 2.2 音系学（Phonology）：声音系统的规则

- **词尾清化**：德语、荷兰语、塞浦路斯希腊语、保加利亚语、韩语、泰语、加泰罗尼亚语中，词尾的浊阻塞音会变成清音：_Madrid → Madrit_。
- **元音弱化**：英语、加泰罗尼亚语、保加利亚语、爱尔兰语中，非重读位置能用的元音更少，常变成**央元音 [ə]**。
  - 英语：_about_ 的 a、_synthesis_ 的 e、_harmony_ 的 o、_medium_ 的 u
  - 加泰罗尼亚语：_mosca → mosquit_
- **音节复杂度**：日语只允许 (C)V(n)；捷克语最多可以到 (C)(C)(C)(C)(C)V(C)(C)(C)。

### 2.3 形态学（Morphology）：词是怎么构成的

| 类型                            | 描述                                     | 例子                                                                                             |
| ------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **分析语（Analytic）**          | 词基本**没有屈折变化**                   | 汉语、越南语；英语、南非荷兰语                                                                   |
| **综合语：黏着型**              | 语素**界限清楚**                         | 土耳其语 _ev-ler-den_"从房子们那里"（_ev_ 房子 + _-ler_ 复数 + _-den_ 从）；韩语、日语……克林贡语 |
| **综合语：屈折 / 融合型**       | 语素与词根之间、语素彼此之间**不易分开** | 大多数印欧语言；西班牙语 _com-er-ía, com-i-ó, com-er-á_                                          |
| **多式综合语（Polysynthetic）** | 一个词相当于其他语言里的**整句话**       | 纳瓦霍语 _bééshbeehane'é_ ="用来和别人双向通话的装置"（电话）                                    |

_课件对第二组只写了"土耳其语、韩语、日语……"，第四组只给了定义；"黏着""融合""多式综合"是我补的通用术语。_

### 2.4 句法：语序

| 语序              | 语言                                                                                                           | 占比   |
| ----------------- | -------------------------------------------------------------------------------------------------------------- | ------ |
| **SVO**（主谓宾） | 英语、西班牙语、普通话                                                                                         | 约 40% |
| **SOV**（主宾谓） | 日语、印地语/乌尔都语、匈牙利语、巴斯克语、（拉丁语）                                                          | 约 40% |
| **VSO**（谓主宾） | 威尔士语、他加禄语                                                                                             | 约 15% |
| 其他              | 如 **OVS**：只有约 11 种语言，外加克林贡语；尤达大师就这么说话（"强大，你已变得。黑暗面，我在你身上感觉到。"） | 约 5%  |

### 2.5 句法加工：关系从句的依附

- "_Someone shot the servant of the actress **who was on the balcony**._"（有人枪击了女演员的仆人，那个在阳台上的人。）谁在阳台上？
  - **低依附**：女演员（离从句最近的名词）
  - **高依附**：仆人（第一个名词）
- 课件的饼图显示：**英语**母语者多选**女演员**，**西班牙语**母语者多选**仆人**。
- 也就是说，句法解析偏好因语言而异，不存在唯一通用的解析策略。
- _这是 Cuetos & Mitchell（1988）的经典发现，课件只给了结果，没有注明出处。_

### 2.6 运动动词中的"方式"与"路径"

- **英语**把**方式**放进动词，路径用小品词表示："He **rolled** down the hill"；"The bottle **floated** out of the cave"。
- **西班牙语**把**路径**放进动词，方式另外表达（或者不表达）："**Bajó** la cuesta rodando"（下了坡，滚着）；"La botella **salió** flotando de la cueva"（瓶子出了洞，漂着）。
- **刺激材料**：动画 _Canary Row_（傻大猫与崔弟，Merrie Melodies）。
- **手势跟着语言走**：
  - 英语母语者倾向于用**一个**翻滚着斜向下的手势（方式和路径合在一起）。
  - 西班牙语母语者可能**先比划"滚"，再比划"向下"**（分开表达）。

### 2.7 层级之间的接口（Interfaces）

- "Juan vio **a** María por la calle" vs "John saw Mary on the street"。
- 各层级相互作用（句法 ↔ 语义 ↔ 形态）。西班牙语要用 **"a"** 标记有生命的直接宾语，英语不用。
- _课件只给了这两个句子，这里的解读是我的推断。_

## 3. 词汇（Lexicon）

### 3.1 什么是"词"？

- "Le miró fijamente y le dijo: dame lo que has escondido en tu bolsillo" 有几个词？_dame_ = 给 + 我。
- 加泰罗尼亚语 _Dona'm-ho_（给-我-它）；法语 _Est-ce qu'il est venu?_ 词的边界并不明显。
- **我们怎么认出词？** 怎么知道 "table" 是词而 "tible" 不是？怎么知道一张狗的图片在英语里叫 "dog"，而不是 "cat"，或者德语的 "Hund"？

### 3.2 心理词典（Mental lexicon）

- 词典里对"词"的定义：
  - "语言中一个有意义、可以说出或写出的单位"
  - "一个或一组有意义的声音……"
- 词典记录一个词的**意义、发音、句法特征**等，**心理词典**也一样。
- **词汇通达**（简化版）：课件引用了 Strijkers & Costa（2011）和 Hickok & Poeppel（2007）。
  - 产出路径：概念 / 语义 → **词汇** → 音节 → 音位 → 发音（感知一侧从频谱时间分析开始）。
  - 以 "cheese"（奶酪）为例：语义 → 词汇（CHEESE vs MILK、YELLOW、SMELL……）→ 语音 → 运动。

### 3.3 研究范式与主要效应

- **词汇判断任务**：这串字母是不是真词？（在线演示：waltervanheuven.net、PsyToolkit、Hanover）
- **启动效应**：语义启动（_doctor → nurse_）、语音启动等。
- **主要效应**
  - **词频效应**：常用词识别更快。
  - **邻域效应**：只差一个字母或音的词。**CAT** 的正字法邻居有 _cot、mat、hat、rat、cut、cast、cart、car、cap、can_……（Siew, 2018）
  - **具体性与可表象性**等。

### 3.4 口语词识别模型

| 模型                                           | 核心观点                                                                                                                                                              |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **群集模型（Cohort）**（Marslen-Wilson, 1987） | 开头的几个音激活以此开头的所有词，形成一个"**群集**"（_s-_ → sled、stack、stagger……）。随着语音输入增加，候选词被逐个排除，直到只剩一个。三个阶段：通达 → 选择 → 整合 |
| **TRACE 模型**（McClelland & Elman, 1986）     | 交互式联结主义网络：**特征 → 音位 → 词**，激活自下而上、自上而下双向传播，同一层内部相互竞争。_课件写的是 1996，原论文是 1986 年。_                                   |

- 通过对变量和时间进程的精巧操纵，心理语言学揭示了心理词典的**动态特性**，并建立了**计算（神经网络）模型**。
  - Chen & Mirman（2013）
  - Rumelhart & McClelland（1986），并行分布式加工
  - 反向传播论文：Rumelhart、Hinton & Williams（1986，_Nature_ 323:533）；课件还配了 2024 年诺贝尔奖的图
- 心理词典是一张**错综复杂的联结网络**，连接语音形式、词汇意义等。
  - 开放问题："语音形式"和"词汇意义"到底是什么？它们在大脑中如何表征？

### 3.5 通达失败的时候

- **舌尖现象（Tip of the tongue, TOT）**
  - 课堂演示：给出一个定义，"航海和测量中用来测天体高度和角距离的仪器"（答案：**六分仪**）。"别把词说出来！"
  - 要记录：你知道这个词吗？有几个音节？第一个音是什么？想到了哪些词？
  - 舌尖状态下，人往往知道词的**部分形式信息**（首音、音节数），却想不起完整的词。这说明**意义和形式是分开存储的**。
- **错语（paraphasia / 口误）**：漫画笑话"弗洛伊德式口误，就是你想说一件事，却说出了你妈"。
- **命名性失语（Anomia）**：一种失语症，病人无法提取名称（视频）。

## 4. 语言与大脑

### 4.1 语义类别（Damasio et al., 1996；2004 年扩展重复）

- 127 名单一、稳定局灶性脑损伤的成年病人，给 327 张图片命名，内容是**名人、动物、工具**。只有在正确认出图片、却说不出名字时（类似舌尖现象）才算命名错误。
- 97 人表现正常，30 人异常。

| 损伤部位                      | 命名障碍       |
| ----------------------------- | -------------- |
| **颞极**                      | **熟人**的名字 |
| **颞下回**                    | **动物**的名称 |
| **颞下回后部 + 枕叶外侧前部** | **工具**的名称 |

→ 不同**语义类别**部分依赖不同的脑区。

### 4.2 具身性：动作词（Pulvermüller, 2005）

- 与**脸、手臂、腿**相关的动作词（_lick 舔、pick 拿、kick 踢_）会激活**运动皮层**的对应部位（躯体定位式激活）。
- 词义部分**扎根于动作系统**，可以和 Interaction Models 课上讲的具身认知联系起来。

### 4.3 大脑中的词汇网络（Hagoort, 2020）

- 一张产出 / 理解网络图：**词汇概念 → 词元（lemma，句法词）→ 音位 → 音节运动程序**，有输入和输出两条通路（Levelt 式模型）。

### 4.4 词类与输出通道（Caramazza & Hillis, 1991）

- 两名失语症病人：
  - **H.W.** 说出**动词**有困难，写没有问题。
  - **S.J.D.** 正好相反：**写动词**有困难，说没有问题。
- 用**名词 / 动词同形词**测试：_a crack / to crack_（裂缝 / 敲开），_a watch / to watch_（手表 / 观看）。
  - "There is a **_ in the window"（窗户上有一道_**）（名词）
  - "Don't *** the nuts in here"（别在这里***坚果）（动词）
- 同一个词形，作为动词受损、作为名词正常，而且只在**一种输出通道**中受损。
- → 词汇知识按**词类**组织，**语音输出词典和书写输出词典是分开的**。

### 4.5 手语

- 手语是完整的自然语言，有自己的语系（世界手语语系分布图）。
- **手语的构成参数**：手形、位置、动作、朝向（相当于口语的音系）。
- ASL（美国手语）有**形态**和**语法**（例如时间放在句首、话题—评论结构）。
- 这是**模态独立性**的证据。

## 5. 讨论题

> _先天失明的英语和西班牙语母语者，在描述 Canary Row 动画时，手势会一样吗？为什么？你的回答说明了语言乃至一般认知的什么特点？_

**参考思路（我的补充）：**

- 相关研究（如 Özçalışkan, Lucero & Goldin-Meadow, 2016，比较英语和土耳其语）发现：**盲人的手势和同语言的明眼人一样**，按自己语言的方式合并或拆分"方式"与"路径"。
- 他们从来没有**看见**过手势，所以这种手势模式**不是靠视觉模仿学来的**，而是来自**语言如何打包事件**。
- 由此可见，语言特有的组织思维的方式（Slobin 所说的"为说话而思考"）会影响身体动作，手势和言语是**一个整合的系统**。
