# 前额叶：执行脑与情绪脑 复习笔记

## 1. 开篇

- **前额叶皮层（PFC）大小的物种比较**：小鼠 → 猴子 → 人。人类的前额叶尤其大。
- **Flanker（侧翼 / Eriksen）任务**（视频，另有儿童版）：
  - 只对**中间**的箭头反应，忽略两边的箭头。
  - 一致：→ → → → →；不一致：← ← → ← ←。
  - 不一致试次更慢。它测量的是**冲突解决**能力（即 Posner 模型中的执行网络）。

## 2. 前额叶的解剖

三个面：**外侧面、内侧面、眶面**。

| 区域                     | 功能                     |
| ------------------------ | ------------------------ |
| **外侧（背外侧）前额叶** | 执行功能的**认知**方面   |
| **内侧和眶额前额叶**     | 行为的**情绪与社会调节** |

这一划分就是本讲的上下两半：**执行脑**和**情绪 / 社会脑**。

## 第一部分 · 执行脑

### 3. 行动中的执行功能

- **前额叶受损不会影响运动本身或动作的执行**，但动作会变得**杂乱无序**，或者**不符合当前目标**。
- **持续性重复（Perseveration）**：重复一个已经做过、已不再相关的动作。
- **利用行为（Utilization behaviour）**：冲动地去摆弄环境中无关的物体。
  - Shallice 等人（1989）的病例：一大早发现病人*穿着别人的鞋*，对简单指令没有反应，_往嘴里塞硬币、去抓想象中的东西_；他在屋里四处走，_挪家具、开柜门、把电灯开关开了又关_。
- 两者都是**被习惯和环境中的物体自动驱动**的行为，而不是**由目标驱动的受控行为**。
- **关键对比：受控行为 vs 自动行为。**

### 4. 需要执行控制的五种情境（Norman & Shallice, 1986）

1. **计划或决策**
2. **纠错或排除故障**
3. **新异情境**
4. **危险或技术上困难的情境**
5. **克服强烈的习惯性反应或抵制诱惑**

_在 Norman & Shallice 的模型中，日常动作由自动的图式完成；这五种情境需要由前额叶实现的**监督注意系统（SAS）**介入。课件只列了五种情境，SAS 这一框架是我补充的。_

### 5. 各情境对应的测验

| 情境              | 测验                                                                                                                      | 说明                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **计划 / 决策**   | **伦敦塔**（汉诺塔的变体）：用最少步数把球摆成目标状态（课件中有 2 步、4 步、5 步的题）                                   | 健康人做题时前额叶激活（脑成像），前额叶受损者表现差           |
|                   | **六要素测验（Six Elements）**                                                                                            | **生态效度高**的计划测验：在有限时间内安排好六项子任务         |
| **纠错**          | **威斯康星卡片分类测验**：按颜色、形状或数量分卡片，规则会**不打招呼地**改变                                              | 病人继续按旧规则分 → **持续性重复**（不能转换策略）            |
| **新异情境**      | **认知估计**（"未知问题"，如成年女性平均身高是多少？）；**FAS 测验**（言语流畅性：1 分钟内说出尽量多以 F、A、S 开头的词） | 没有现成的答案，必须自己想出策略                               |
| **困难 / 高负荷** | **数点击声**；**n-back 任务**（当前项目是否和 n 步之前的相同？）                                                          | 工作记忆负荷                                                   |
| **克服习惯**      | **Stroop 测验**：说出颜色词的**墨水颜色**（红墨水写的 "GREEN"）                                                           | 读字是自动的，必须加以抑制。脑成像和损伤研究都指向**前扣带回** |
|                   | **Simon 任务**：蓝色举右手，红色举左手                                                                                    | 圆圈出现在与应答手**相反**的一侧时，反应更慢（空间冲突）       |

_六要素测验出自 Shallice & Burgess（1991）。威斯康星、FAS、n-back、Simon 几项课件只给了图或题目，表中的结果解释是通用知识，由我补充。_

### 6. 发育与动作网络

- **前额叶是大脑中最后发育成熟的部分。**
  - 课件展示了约 5 到 20 岁的灰质成熟过程（Gogtay 等 2004 风格的图）：额叶皮层最晚成熟，要到青春期后期和成年早期。
- **棉花糖实验**（Mischel）：孩子能不能忍住现在不吃一块，等着拿两块？自控能力随前额叶一起发展。
- **完成动作需要一个网络**：**前额叶**（制定动作计划）→ 运动前区和辅助运动区 → 初级运动皮层，同时有顶叶（空间知觉）、颞叶（听觉记忆）和枕叶（视觉知觉）的输入。
- 病人视频：计划障碍（三段）。

## 第二部分 · 情绪与社会脑

### 7. 读心

- 想法、感受、意图都是**私人的、主观的**。
- 但人类可能进化出了从行为中**推断**他人想法和感受的能力：看对方的面部表情、视线方向，或者设想自己处在那种情境下会有什么感受。
- 这种能力叫作**心理理论**。

### 8. 共情与模拟理论

- **模拟理论**：**感知**一个动作或情绪，与**产生**这个动作或情绪，**共用**同一套认知资源。
- 看到别人受伤或开心时，我们会（真切地）感受到自己受伤或开心的经验，因此能够共情。
- 证据：
  - **看到别人被触碰**，会激活我们自己的**躯体感觉系统**。
  - **看到所爱的人受到轻微电击**，会激活一部分和自己受电击时相同的脑区。
- 这也是我们爱看**电影、小说**的基础，现实中的社会交往同样如此。
- 这可以和 Interaction Models 课上讲的镜像神经元（Gallese）联系起来。

### 9. 自闭症

- **Leo Kanner（1943）**提出了"自闭症"这个术语。他描述了 **5 岁的 Donald**：手指做刻板动作，反复哼同一个三音符的小调，特别喜欢转东西，进屋后完全无视人、直奔物件，会生气地推开挡路的手。
- **Hans Asperger（1944）**独立描述了这种状况，后来有一个亚型以他的名字命名。
- **诊断特征**：
  - **社会交往和沟通**的发展明显异常或受损
  - **兴趣和活动范围**明显狭窄
- 这是一种**3 岁前就能察觉、并伴随终身的发育性状况**。严重程度和表现会随时间变化，现在被看作一个**谱系**。
- **阿斯伯格综合征**：正式定义是**早期语言和认知发展没有延迟**（不过新的研究表明，早期表现并不能预测后来的功能水平）。有时也用来指"高功能"自闭症（智商正常）。
- 课件中的数据：
  - **约 40%** 的自闭症人士智商低于 70（课件用的是过时的说法"智力迟滞"，现在称为智力障碍）
  - **只有约 10%** 有**学者症候群式的特殊才能**（如凭记忆画画、心算）
- _我的补充：自 DSM-5（2013）起，阿斯伯格综合征不再是独立诊断，而是归入**自闭症谱系障碍（ASD）**。_

### 10. 自闭症儿童有心理理论吗？Sally–Anne 任务

1. Sally 把球放进自己的**篮子**，然后出去散步。
2. Anne 把球挪到了自己的**盒子**里。
3. Sally 回来了。**她会去哪里找球？**

- 正确答案：**篮子**。Sally 没看到球被挪走，所以她持有一个**错误信念**。
- _Baron-Cohen、Leslie & Frith（1985）的结果（我的补充）：大多数正常发育的 4 岁儿童和唐氏综合征儿童会答"篮子"，而多数自闭症儿童答"盒子"。这说明他们在表征**他人的信念**（心理理论）上有困难。课件只给了任务图和视频，没有写结果。_
