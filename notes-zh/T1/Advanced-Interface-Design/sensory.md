# 感官替代与增强（Sensory Substitution & Augmentation）

## 0. 核心框架

### 0.1 重新映射感官的两种方式

|        | **感官替代（Substitution）**                            | **感官增强（Augmentation）**                       |
| ------ | ------------------------------------------------------- | -------------------------------------------------- |
| 是什么 | 通过**完好的**感官，传递**丧失或受损**感官的信息        | **增加**人类原本感知不到的信息，或**扩展**现有感官 |
| 例子   | **BrainPort**：盲人通过舌头上的电刺激图案感知摄像头画面 | **feelSpace 腰带**：始终在朝向磁北的一侧振动       |
| 目标   | **恢复**获取信息的通道                                  | 获得一种**新的或更宽的**感官                       |

- **同一个设备可以兼任两种角色。** 颜色 → 声音，对色盲用户是替代色觉，对其他人则是给图像加了一层声音。
- 参考：Shull & Damian (2015)；Eagleman & Perrotta (2023)；Bach-y-Rita & Kercel (2003)。

### 0.2 信息的来源与目标：各种感官

| 感官           | 承载什么信息                         |
| -------------- | ------------------------------------ |
| 视觉           | 形状、颜色、运动、距离               |
| 听觉           | 音高、响度、方向、言语               |
| 触觉           | 压力、振动（约 5–400 Hz）、温度      |
| 本体感觉       | 关节角度、肌肉力量                   |
| 前庭觉         | 头部转动、加速度、重力               |
| 嗅觉           | 空气中的化学物质                     |
| 味觉           | 甜、咸、酸、苦、鲜                   |
| **非人类信号** | 磁场、红外线、距离（声呐、激光雷达） |

### 0.3 所有映射都是同一个闭环

**传感器 → 特征提取 → 编码（映射）→ 执行器 → 感知**，而**身体动作**（指向、转头、走路）会改变传感器测到的内容。闭环靠行动来闭合。

- 例子：**vOICe**（视觉 → 听觉）
  - 头戴摄像头 → 提取图像每一列的灰度
  - 编码：**x → 时间，y → 音高，亮度 → 响度**
  - 耳机每秒播放一段"声景"
- **两个设计决策**：**特征**（保留什么）和**编码**（用哪个刺激参数承载哪个特征）。

### 0.4 三种映射

| 类型                        | 原理                                                                                    | 例子                            |
| --------------------------- | --------------------------------------------------------------------------------------- | ------------------------------- |
| **拓扑映射（Topographic）** | **位置 → 位置**：一个像素驱动同一位置的执行器；外界某个方向，就在身体上的同一方向感受到 | TVSS、BrainPort、feelSpace 腰带 |
| **参数映射（Parametric）**  | **特征 → 参数**：高度 → 音高，亮度 → 响度，倾斜 → 振动强度                              | vOICe、平衡腰带、动作声化       |
| **符号映射（Symbolic）**    | **先识别 → 再编码**：音位 → 触觉图案；声音 → 字幕或图标                                 | 音位触觉袖套、声音感知眼镜      |

- **经验法则：来源信息越丰富、目标通道越贫乏，映射之前需要的预处理就越多。**

### 0.5 各目标感官能承载什么

| 目标感官   | 编码维度                                         | 主要限制                         |
| ---------- | ------------------------------------------------ | -------------------------------- |
| **触觉**   | 身体部位、频率（约 40–400 Hz）、振幅、节奏、扫动 | 振动器之间需要厘米级间距；会适应 |
| **听觉**   | 音高、响度、音色、三维位置、节奏、言语           | **会盖住真实环境声音**；容易疲劳 |
| **视觉**   | 位置、大小、颜色、运动、文字、符号               | 占用双眼；画面杂乱               |
| **前庭觉** | 倾斜或运动提示的时机和方向                       | 信息速率低；电刺激可能不舒服     |
| **嗅觉**   | 哪种气味或组合、强度、出现时间                   | 以秒计的慢；残留；会适应         |
| **味觉**   | 电流、频率、极性；温度                           | 主要能产生酸、咸、苦，甜味很弱   |

### 0.6 组合矩阵（来源 → 目标）

| 来源 ↓ / 目标 → | 视觉           | 听觉                | 触觉                     | 前庭      | 味觉     |
| --------------- | -------------- | ------------------- | ------------------------ | --------- | -------- |
| **视觉**        | 棱镜           | vOICe、EyeMusic     | TVSS、BrainPort、EyeCane | VR → 振动 | AR 风味  |
| **听觉**        | 声音头显、字幕 | 频率下移            | 音位袖套、VEST 背心      | —         | 声音调味 |
| **触觉**        | 力显示         | Sensor Glove        | 反馈转移部位             | —         | —        |
| **本体感觉**    | 视觉反馈       | 声化                | TIKL 套装                | —         | —        |
| **前庭**        | RGS            | RGS                 | 倾斜腰带、舌头           | 植入物    | —        |
| **嗅觉**        | —              | —                   | 电子鼻 → 三叉神经        | —         | —        |
| **非人类信号**  | 红外相机       | hearSpace、颜色声音 | feelSpace、Haptic Radar  | —         | 电味觉   |

- 课件用颜色区分每格属于替代、增强还是同感官重映射；"—"表示没有已发表的研究。
- **嗅觉作为目标**的那一列全空，这里省略了。
- **味觉作为来源**的那一行也全空。

## A 部分 · 感官替代

### A1. 视觉 → 触觉（以拓扑映射为主）

| 年份     | 设备                    | 要点                                                            |
| -------- | ----------------------- | --------------------------------------------------------------- |
| **1966** | **Optacon**             | 一只手拿摄像头扫描印刷文字，另一只手的指尖在针阵上摸到每个字母  |
| **1969** | **TVSS**（Bach-y-Rita） | **背上 400 个振动器**；盲人参与者学会了识别物体                 |
| **1998** | 舌头显示器              | 49 点电触觉阵列可以识别形状；后来的 **BrainPort** 用 **400 点** |
| **2014** | **EyeCane**             | 一个距离读数 → 振动；训练**几分钟**就能避障                     |

- BrainPort 的映射：眼镜上的摄像头 → 画面缩减到电极网格 → 每个像素驱动舌头上同一位置的电极 → **亮度 → 刺激强度**。
- 新近设备：_Seeing with the Hands_（CHI 2025，芝加哥大学 Pedro Lopes 实验室）；Biped NOA 导盲背带；WeWalk 智能手杖 2（探测离地障碍物，提供导航，用振动和语音提示）；触觉平板（Field of Vision）。
- **"它在哪？两个振动器就够了"**（Wald et al., CHI 2025）
  - 每只手（或每只耳朵附近）一个振动器，离目标越近振动越强，原理和**两耳之间的响度差**一样。
  - 只用 **2 个振动器**（低成本、低算力），**不经训练**就能分辨相距**不到 30°** 的目标。
  - 新思路：把**双手当作"能移动的耳朵"**来找东西。

### A2. 视觉 → 听觉（参数映射）

- 编码：**y → 音高**（越高频率越高），**亮度 → 响度**，**x → 时间**（扫描一遍约 1 秒）。
- 设备：
  - **vOICe**：头戴摄像头，逐列扫描
  - **PSVA**：像素网格 → 频率
  - **EyeMusic**（2014）：**颜色 → 乐器**
- 经过 vOICe 训练后，用户能定位和识别物体（Auvray et al., 2007）。
- **EyeMusic**：盲人大脑中与视觉加工相关的区域被调用来"阅读"，这是**跨通道可塑性**的证据。
- ⚠️ **导航：App vs 普通白手杖**。7 名盲人、训练 10 小时后，摄像头转声音的 App 在避障上**没有胜过**普通手杖。**手杖是任何新设备必须超越的基线。**

### A3. 听觉 → 触觉

| 策略             | 做法                                                          | 结果                                                                                     |
| ---------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **频谱（位置）** | 滤波器组：每个频段 → 一个振动器，相当于"**触觉耳蜗**"（VEST） | —                                                                                        |
| **音位（符号）** | 言语 → 音位 → 每个音位对应一种由位置、频率、振幅组成的图案    | 前臂 24 个振动器编码 39 个音位，训练 1–4 小时后音位识别率达 **86%**（Reed et al., 2019） |
| **包络**         | 言语振幅包络 → 手腕振动，与人工耳蜗同时使用                   | 人工耳蜗用户在噪声中识别词语 **+8.3 个百分点**（Fletcher et al., 2019）                  |

- **Neosensory Buzz 手环**：
  - 麦克风收音 → 声音分成 **4 个频段** → 驱动 4 个马达（低音在手腕一侧，高音在另一侧）；越响振动越强。
  - 它从 **VEST** 发展而来（2015 年，躯干上 32 个马达；Eagleman 的 TED 演讲）；2020 年前后推出 Buzz，手腕上 4 个马达，更便宜，可以全天佩戴。
  - 模式：日常声音、音乐、睡眠（闹钟）。
  - 聋人用户学会了通过振动识别日常声音（Perrotta et al., 2021）。它有**开放 API**：任何数据都能驱动这 4 个马达，也被用来做新感官。
  - ⚠️ **Neosensory 于 2025 年关闭**并出售技术，用户失去了 App 和支持。**设计教训：要为公司消失做好准备**（开放格式、可离线使用）。
- **振动背心**：
  - 映射：频段 → 躯干上的位置；**节拍和节奏传达得好，旋律和音高传达得差**。
  - 例子：Not Impossible 在音乐会上用的振动服；Woojer、SUBPAC（音乐、游戏）；VR 触觉背心。
  - 优点：皮肤面积大；眼、耳、手都空着；可以共享音乐会体验。
  - 缺点：笨重、闷热、要充电；空间分辨率低；音高和音色会丢失。

### A4. 人工耳蜗：电子听觉

- 耳后的处理器把声音分成频段 → 经皮肤无线传输 → 耳蜗内 **12–22 个电极**刺激听神经。
- **位置映射，与耳朵一致**：高频在耳蜗底部，低频在顶部。
- 全球植入量 **超过 100 万**（NIDCD, 2022）。
- 安静环境下听言语效果好；噪声和音乐中困难（通道少，音高感差）。
- 训练有帮助（旋律识别 +27 个百分点，6 名用户），触觉也有帮助（手腕振动使噪声中的词语识别 +8.3 个百分点）。

### A5. 听觉 → 视觉

- 麦克风阵列 → **声源方向**；分类器 → **声音类型**（说话、警报、门）；语音识别 → **字幕**。
- 头显中显示方向箭头、声音名称和字幕（如"门铃，左边"；"能把盐递给我吗？"）。
- 2003 年：屏幕上的外围声音显示帮助聋人注意到办公室里的声音（Ho-Ching et al.）。
- 2015 年：头戴式方向可视化，在 24 名聋人和听障用户中评估（Jain et al.）。

### A6. 平衡 → 触觉、听觉或视觉

**流程**：头部或躯干上的 IMU → 倾斜角 → **死区**（忽略小幅摇摆）→ 映射

| 目标     | 映射                                                                                            | 证据                                                         |
| -------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| **触觉** | 身体倾向哪侧，哪侧的振动器就振；倾斜越大 → 振动位置越高或脉冲越快。舌头版：倾斜会让图案偏离中心 | 前庭功能丧失者摇摆减少（Wall 2001；Sienko 2008；Tyler 2003） |
| **听觉** | 前后摇摆 → 音高；左右摇摆 → 立体声左右平衡                                                      | 双侧前庭功能丧失者站在泡沫垫上、闭眼时摇摆减少（Dozza 2005） |
| **视觉** | 压力中心 → 屏幕上的一个点；把点保持在目标区内                                                   | 老年人平衡训练中常用（Zijlstra 2010）                        |

- **双侧前庭功能丧失**
  - 症状：站不稳，在黑暗中或软地面上更严重；**振动幻视**（走路时觉得世界在跳）；跌倒，以及对跌倒的恐惧。
  - 原因：耳毒性抗生素（庆大霉素）、梅尼埃病、脑膜炎、原因不明。
  - **干预手段，从最不侵入到最侵入**：
    1. 康复训练（更多依赖视觉和本体感觉）
    2. 感官替代（倾斜 → 振动、舌头刺激或声音）
    3. 噪声电刺激
    4. 前庭植入物
- **案例：Cheryl Schiltz（2003–2004）**
  - 她因庆大霉素失去前庭功能，总觉得自己在往下倒。头上的加速度计驱动舌头上的图案，身体一倾斜图案就偏离中心，她通过调整身体让图案回到中心。
  - 戴上设备后，她能稳定地站立和行走。
  - **残留效应**：反复训练后，效果能持续到每次训练结束之后，从几分钟到几小时再到半天（Tyler 2003；Danilov 2007）。
  - ⚠️ 注意：研究规模小、大多没有对照组；设备本身的效果和配合设备做的训练无法分开。
- **设计问题**：设备戴着时有帮助，取下后大脑能保留一部分效果吗？
- **可穿戴平衡辅助设备**

| 设备        | 设计                                   | 结果                                                                            |
| ----------- | -------------------------------------- | ------------------------------------------------------------------------------- |
| BalanceBelt | 腰带；身体倾向哪侧就在哪侧振动         | 31 名居家用户中 23 人改善：1 个月后评分从 4.2 升到 7.9（满分 10，**无对照组**） |
| Vertiguard  | 头戴传感器；训练时躯干周围的振动器提示 | 每天 15 分钟，持续 2 周；与**假设备**对照（多中心研究）                         |
| 手机训练器  | 手机 IMU 放在躯干上 + 振动器；在家训练 | 老年人；有振动 vs 无振动的随机试点研究（12 人）                                 |

- **课上就能做**：Grove IMU → 倾斜角 → 死区 → 在倾斜一侧驱动振动马达。
- **超越替代的方法**
  - **噪声前庭电刺激**：耳后电极通入微弱的随机电流，人感觉不到。原理是**随机共振**：噪声让残存的微弱信号变得可以被检测到。站立时摇摆减少（2014），行走更稳（2016）；**19 名患者中 12 人有反应**，平均摇摆**减少 31%**（Wuehr et al., 2023）。
  - **前庭植入物**：头部运动传感器 → 半规管神经上的电极。8 名患者的姿势、步态和生活质量改善（Chow et al., 2021）。风险：植入侧耳朵可能听力下降（8 人中 3 人下降明显）。日内瓦—马斯特里赫特原型：人工耳蜗电极 + 三个前庭电极。

### A7. 触觉与力 → 听觉、视觉、触觉

| 映射          | 例子                                          | 结果                                   |
| ------------- | --------------------------------------------- | -------------------------------------- |
| → 听觉        | **Sensor Glove**：指尖麦克风 → 耳机里的立体声 | 神经修复 12 个月后触觉识别更好         |
| → 视觉 / 听觉 | 手术：器械尖端的力 → 音高或彩色条             | 在机器人辅助打结任务中对比测试         |
| → 别处的触觉  | 假肢：指尖压力 → 残肢上的振动或压力           | 抓握控制更好，假肢"属于自己"的感觉更强 |

- **模态匹配**更好：压力 → 压力感觉自然；压力 → 振动更容易实现。

### A8. 嗅觉 → 触觉（Stanley et al., 2025, _Science Advances_）

- 电子鼻（气体传感器阵列）→ 气味编码 → 夹在**鼻中隔**上的电极 → **三叉神经**，产生类似触觉的感受。
- 测试对象：13 名嗅觉正常者 + 52 名嗅觉丧失者。
  - **检测有效**：用户能察觉到有气味出现。
  - **区分更难**，不过多数人能分辨两种气味。
- **是替代，不是恢复**：用户感受到的是气味的编码，并没有闻到它。

### A9. 空白领域与同感官重映射

- **几乎没有研究的方向**：
  - 味觉作为信息来源
  - 嗅觉 → 听觉或视觉
  - 任何感官 → 味觉或嗅觉（作为替代）
  - 原因：这些感官慢（以秒计）、适应快、信息速率极低。
- 实际中，对没有嗅觉的人用的是**符号映射**：燃气和烟雾探测器响警报，或推送到手机。
- **同感官重映射**：
  - **视觉**：用棱镜把部分画面移到残存的视野里（Peli, 2001）。
  - **听觉**：频率下移，把高音（如 "s"）移到还能听到的频段。
  - **触觉**：把假肢的反馈转移到完好的皮肤上。

## B 部分 · 感官增强

### B1. 磁北 → 触觉或听觉

- **feelSpace 研究腰带**（Nagel et al., 2005；Kaspar et al., 2014）：朝北的振动器振动。佩戴**几周**后，用户报告**空间感发生了变化**。
- **naviBelt**：商业版，16 个振动单元，为盲人提供指南针和导航。
- **hearSpace**（Schumann & O'Regan, 2017）：耳机播放一个听起来永远来自北方的声音。向右转，声音就移到左耳，像远处的教堂钟声。

### B2. 距离与红外 → 触觉

- **Haptic Radar（2006）**：头部一圈距离传感器，每个驱动它下方的振动器（越近越强），像是一层"**延伸的皮肤**"，在接触之前就能感觉到。**87%** 的参与者会移动身体，避开看不见的接近物体。
- **红外 → 触觉皮层（2013）**：大鼠身上的红外探测器驱动**初级体感皮层 S1** 的微电刺激。大鼠学会了寻找红外光源，胡须触觉仍然正常。这是侵入式的（植入电极）。
- 不用植入的办法：**热成像相机**把红外显示成颜色（视觉 → 视觉）。

### B3. 颜色 → 声音

- 平板上手指下的颜色 → 声音：**色相 → 音色或音高；明度 → 音高；饱和度 → 响度**。
- 按照**人们共有的跨通道对应关系**编码，比随意编码记颜色、认物体都更好（Hamilton-Fletcher et al., 2016）。

| 视觉特征     | 声音特征       |
| ------------ | -------------- |
| 空间位置更高 | 音高更高       |
| 更亮、更浅   | 音高更高、更响 |
| 更大         | 音高更低       |
| 形状更尖锐   | 音色更明亮     |

- **Neil Harbisson** 通过头上的摄像头天线"听"颜色。
- **设计规则：顺着人们共有的对应关系设计，用户学得更快**（Spence, 2011）。

### B4. 动作 → 触觉或声音

- **TIKL 动作学习套装**（Lieberman & Breazeal, 2007）：
  - 测量关节角度与老师动作之间的误差
  - 在应该移动的方向那一侧振动，强度与误差成正比
  - 需要旋转时，振动器绕肢体依次振动
  - 比只看视觉示范学得更快

| 动作量           | 声音参数   |
| ---------------- | ---------- |
| 位置             | 音高       |
| 速度             | 响度或音高 |
| 左右位置         | 立体声声像 |
| 步伐、划桨的节奏 | 速度、节拍 |

- 用途：赛艇、骑车、步态和手臂康复。**要逐渐把声音淡出，避免用户产生依赖。**

### B5. 味觉、风味与 VR 中的运动

- **视觉 + 嗅觉 → 味觉**：AR 让一块普通饼干看起来、闻起来像另一种饼干，它尝起来的味道也随之改变（Narumi et al., 2011）。
- **听觉 → 味觉**：增强咬薯片声音中的高频成分，薯片吃起来**更脆、更新鲜**（Zampini & Spence, 2004；"声音调味"）。
- **数字 → 味觉**：用电流、频率、极性刺激舌头，能产生酸、咸、苦，甜味很弱（Ranasinghe & Do, 2016）。
- **视觉 → 前庭**：在虚拟场景转弯时振动耳后，能减轻 **VR 晕动症**（Weech et al., 2018）。

## C 部分 · 用交互界面做康复

### C1. 交互界面为什么对康复有帮助

闭环：传感器（摄像头、IMU、测力台）→ 动作特征 → 游戏或 VR → 反馈 → 患者再做动作

| 优势                | 说明                                                              |
| ------------------- | ----------------------------------------------------------------- |
| **重复次数**        | 每次训练能做几百次动作，传统康复每次只有约 **32** 次（Lang 2009） |
| **动机**            | 游戏有目标、分数和进度，患者愿意练更久                            |
| **自适应难度**      | 传感器测量表现，患者进步时任务随之变难                            |
| **改变感知**        | VR 和镜子让患侧肢体"看起来"动得更好，对抗**习得性废用**           |
| **测量**            | 每个动作都被记录，进步看得见                                      |
| **居家 / 远程康复** | 便宜的传感器（摄像头、手机）让出院后也能继续训练                  |

- **核心观点：交互界面是一种为了让大脑重新学习而设计的感官映射。**

### C2. 康复游戏系统（Rehabilitation Gaming System, RGS）

- Kinect 追踪双臂；以**第一人称**看到虚拟手臂；游戏有伸手、拦截、抓取；**难度实时自适应**。
- 急性中风试点随机对照试验（8 + 8 名患者，12 周）：用 RGS 的组手臂恢复更快，Fugl-Meyer 和 Chedoke 评分更好。
- 从实验室到临床：**Eodyne Systems**（UPF 衍生公司，2014）；有医院版和居家版（RGS@home）。
- **把 RGS 看作感官映射**：
  - **核心**：手臂和手指的动作（**本体感觉**）→ 摄像头 + 数据手套 → 虚拟手臂（**视觉**），目标和分数也在虚拟场景里。
  - 听觉用于任务提示（语音指令），但这不是对动作本身的映射。
  - 可扩展：触觉力反馈（其他 VR 系统）、手臂位置声化。
  - **多模态刺激**：RGS 想激活完好的神经系统（看到自己的动作），由它来驱动受损的运动区（Cameirão et al., 2009）。
- **放大动作**：
  - 问题：**习得性废用**。患侧手臂因为总是失败，患者就不用它。
  - 方法：让**虚拟手臂比真实手臂伸得更远、更准**。
  - 结果：患侧手臂用得更多，**取消放大后依然如此**（20 名患者）。
  - **RIMT（2016）**：双盲随机对照试验，18 名慢性期患者，6 周。
  - 中风**超过 1 年**后仍然可能恢复（219 名患者，2019）。
  - 与本课的联系：这是一种**增益 > 1** 的感官映射，和平衡腰带中放大倾斜是一个道理。

### C3. 镜像与错觉

- 镜子挡住患侧肢体，映出健侧肢体，所以动健侧时看起来像是患侧在动。这种错觉会激活患侧对应的运动区。也用于治疗幻肢痛。
- **Cochrane 综述（2018）**：62 项研究，1982 名参与者；治疗结束时运动功能改善，**标准化均差（SMD）0.47**。
- 开放问题：效果能持续吗？只有 2 项试验在 6 个月时做了测量。

### C4. 姿势与平衡反馈

- 测力台或 Wii 平衡板 → **压力中心** → 屏幕上的点；把重心移向较弱的那条腿；做游戏。与 A 部分的"平衡 → 视觉"映射相同。
- 证据：
  - 测力台（Cochrane）：站姿对称性改善，但平衡能力和生活独立性没有明显改善
  - **Wii Fit**（20 名患者）：改善程度和传统治疗一样，没有更好
  - 机器人步态训练 + VR（Lokomat）：增加了反馈和动机，但它本身的效果还没确立
- **教训：反馈会改变练的是什么，要检查能否迁移到日常生活。**

### C5. 商业与居家系统

- **MindMotion PRO**（MindMaze）：摄像头把动作映射到虚拟化身上；通过 FDA 510(k)；它的随机对照试验提前终止。
- **SWORD Health**：可穿戴动作传感器 + 平板，在家使用。下背痛随机对照试验（140 人）：效果与面对面治疗相当，退出的人更少。
- **RGS@home**（Eodyne）：在家玩 RGS 游戏，治疗师远程监测。
- 居家康复的训练量更大、成本更低，但**参与度、监督和安全**成了新的设计难题。

### C6. 证据怎么说

- **Cochrane 2017**（72 项研究）：VR 对比传统治疗**并不更好**，**作为补充**有帮助。
- **2025 年更新**（190 项试验）：小幅获益；作为常规治疗的补充时效果中等。
- **EVREST**（Wii 对比纸牌游戏）：同样时长的娱乐活动带来同样的手臂恢复。
- **康复界面的设计原则**：
  - **训练量**：让大量重复变得可行、有动力。
  - **任务**：练日常生活中重要的动作，检查迁移效果。
  - **反馈**：自适应难度；谨慎使用感知手段（放大、镜像）。
  - **证据**：要和**同等训练量**的传统练习对比。
- **一句话：交互界面有用，是因为它增加了精心选择的练习，而不是因为它高科技。**

### C7. 2021 年以来的前沿进展

| 年份 | 事件                                                                | 映射                     |
| ---- | ------------------------------------------------------------------- | ------------------------ |
| 2021 | **Vivistim** 获 FDA 批准：每次手臂动作都配合一次迷走神经刺激        | 动作 → 神经刺激          |
| 2021 | **IpsiHand** 获批：脑电（EEG）脑机接口驱动手部矫形器                | 意图 → 自己的手动起来    |
| 2023 | 脊髓刺激让 2 名中风幸存者恢复手臂运动                               | 尝试动作 → 脊髓刺激      |
| 2023 | **InTandem** 成为处方器械；87 人的随机对照试验于 2024 年发表        | 步伐 → 音乐节拍          |
| 2024 | 荟萃分析：脑机接口 + 电刺激；VR 用于平衡和步行（43 项随机对照试验） | 意图 → 肌肉；身体 → 视觉 |
| 2025 | Cochrane VR 综述更新（190 项试验）；InTandem 获得美国医保编码       | 证据与支付               |

- **趋势：把意图、刺激和反馈连成闭环，并带回家里。**
- **与动作配对的刺激**：
  - **迷走神经刺激（Vivistim）**：植入式刺激器在每次重复动作时发放一串脉冲，强化当下被使用的神经回路。108 人中，Fugl-Meyer 手臂评分提高 **5.0 vs 2.4 分**（VNS 组 vs 假刺激组，6 周）；90 天时达到有临床意义改善的比例 **47% vs 24%**（Dawson et al., 2021）。
  - **脊髓刺激**（2023）：电极放在颈段脊髓上，在患者尝试动作时刺激。2 人的抓握和手臂位置感改善。
  - **设计思路：时机就是界面。** 刺激只有和动作配对时才有用。
- **用于康复的脑机接口（BCI）**：
  - 脑电中的动作意图 → 分类器 → 功能性电刺激（FES）或手部矫形器 → 患者感受到动作。
  - 映射：**意图 → 本体感觉**；即使完全不能自主运动也能用。
  - 手臂功能 SMD 0.50（BCI + FES，10 项随机对照试验，290 名患者，2024）；BCI 训练 SMD 0.56（13 项随机对照试验，258 人，2022）。
  - 局限：试验规模小、设备昂贵、每次都要花时间准备。
  - 用课程框架来看：**分类器是"特征提取"，矫形器是"执行器"**。
- **用节奏引导步行（InTandem）**：
  - 鞋内传感器检测步伐 → 步频 → 音乐节拍随之调整 → 步伐跟着节拍走。
  - 87 人：步速比单独走路多提高 **0.14 vs 0.06 m/s**；有效者比例 **40% vs 13%**。
  - 2023 年成为 II 类处方器械；2025 年获得美国医保编码。
  - 与本课的联系：B 部分"动作 → 声音"的闭环版本，**节拍快慢就是自适应难度**。
- **平衡与步行**：
  - VR 综述（2024）：43 项随机对照试验，1136 名慢性期中风患者。
  - 足底压力 → **振动反馈**，在静态平衡和对称性上**优于视觉反馈**（24 人，2022），而且不占用眼睛。
  - 软体外骨骼（2023）：抬脚高度 +22%，蹬地力量 +22%，步速快约 7%（19 人）。
- **居家传感器康复**：FitMi 传感器游戏 vs 纸质练习，Fugl-Meyer 手臂评分 **8.0 vs 3.0**（亚急性期中风）。
- **趋势与开放问题（2026）**：
  - 闭环：刺激、声音或画面与每个动作或意图同步
  - 真实生活中的测量：可穿戴设备统计在家时手臂的使用情况，而不只看诊室评分
  - 监管与支付：FDA 批准和医保编码决定设备能否到达患者手中
  - 试验规模小、常由企业资助；应与同等训练量的传统练习对比

### D2. 四类眼镜

| 类型                           | 带来什么                                                     | 例子                                                      |
| ------------------------------ | ------------------------------------------------------------ | --------------------------------------------------------- |
| **摄像头 + 音频 + AI，无显示** | 一个声音为你描述、朗读、翻译摄像头看到的东西                 | Ray-Ban Meta、Android XR 音频眼镜                         |
| **小型抬头显示**               | 在视野一角显示文字、图标、字幕                               | Google Glass、Meta Ray-Ban Display、Vuzix Blade、字幕眼镜 |

- **谷歌**：Google Glass 提供免手持的显示屏和摄像头（Envision 在它上面为盲人开发了阅读和场景描述功能），但引发隐私争议，显示屏小、续航短、售价 1500 美元。Android XR（2025–2026）：Gemini 能看到你看到的东西；与 Warby Parker、Gentle Monster 合作镜框；先推音频眼镜，显示版稍后推出；存在云端 AI 和隐私问题。
- **Meta**：
  - **Ray-Ban Meta**：外观像普通眼镜；通过 **Be My Eyes**，志愿者能透过眼镜帮盲人看东西。缺点：摄像头隐私问题，依赖手机和 Meta 的云端，续航只有几小时。
  - **Ray-Ban Display**（799 美元）：右侧镜片有显示屏 + **Neural Band 肌电腕带**，能读取细微的手指手势。评测显示续航不到宣称的 6 小时；重 69 克。

- **透视式 vs 视频透视**：
  - **透视式**：直接看到真实世界，没有延迟；但能显示图形的视场小，户外图形很淡。
  - **视频透视**：每个像素都能改（放大、实时识别）；但重（500–650 克）、续航约 2 小时、让人与外界隔绝、价格高。

### D3. VR 头显

- 屏幕填满视野，耳机填满声音，于是**视觉和听觉都被替换了**；头部追踪让画面跟着头动。
- **感官冲突**：眼睛看到运动，内耳却感觉不到 → **晕动症**。缓解办法：瞬移、缩小视野、耳后振动。
- 用途：前庭康复（小规模研究）；**在真正做出新感官设备之前，先在 VR 里做原型**。
- **VR 是最彻底的替代：它为眼睛和耳朵替换了整个世界，但身体保留着自己的前庭和本体感觉信号。**

### D4. 眼动追踪

- **瞳孔中心 + 角膜反射法**：
  1. 红外 LED 照亮每只眼睛。
  2. 小摄像头每秒多次拍摄眼睛。
  3. 软件找到瞳孔中心和 LED 的反光点。
  4. 经过校准（注视几个点）后，**两者之间的向量**就给出注视方向。
- 中央凹能看清的范围约 **2°**（相当于伸直手臂时一个拇指指甲的大小）；**眼跳**是注视点之间的快速跳动，**约每秒 3 次**。
- 难点：眼镜、化妆、眼睑遮挡；**延迟**（必须在眼睛落定之前更新画面）；头显移动造成的漂移。
- 有眼动追踪的设备：Vision Pro（"看 + 捏"是主要输入方式；Optic ID）、Galaxy XR、PS VR2、HoloLens 2 / Magic Leap 2、Valve Steam Frame、Meta Orion。
- 没有的设备：Google Glass、Ray-Ban Meta、Quest 3/3S。科研设备：Tobii、Pupil Labs。
- **用途**：
  - **注视点渲染**：只在你看的地方全精度渲染（PS VR2 演示中 GPU 帧时间快 3.6 倍）
  - **注视作为输入**：看 + 捏；停留控制（只靠注视就能选择）
  - **社交临场感**：能与人对视的虚拟化身
  - **无障碍**：为无法活动的人（如渐冻症患者）提供注视打字和控制
  - **健康与研究**：前庭检查中的眼动；研究人们看哪里
  - ⚠️ **隐私风险**：注视会暴露兴趣、疲劳、情绪和健康状况。Vision Pro 只把"点击"交给应用，不提供注视数据。

### D5. 为单一感官设计的眼镜

| 设备                                | 映射                                                        | 优点 / 缺点                                 |
| ----------------------------------- | ----------------------------------------------------------- | ------------------------------------------- |
| **.lumen**                          | 视觉 → 触觉：摄像头 + AI 找到安全路径，额头上的振动引导方向 | 测试中不需要手杖 / 头戴设备重、价格高       |
| **Envision**                        | 视觉 → 听觉：朗读文字、描述场景、呼叫帮手                   | 能用在普通眼镜上 / 只有语言输出、依赖云端   |
| **字幕眼镜**（XRAI Glass、Captify） | 听觉 → 视觉：语音 → 镜片上的字幕                            | 能跟上对话、可翻译 / 有识别错误、显示挡视线 |
| **Nuance Audio**                    | 听觉 → 听觉：镜框里的助听器（定向麦克风、开放式扬声器）     | 耳朵里不用塞东西 / 只适合轻度到中度听力损失 |

### D6. 小结

- 各类设备都有取舍：摄像头 + AI（外观普通，但有隐私问题）；抬头显示（一瞥即可，但屏幕小）；透视式 AR（直接看到真实世界，但图形窄）；视频透视（完全掌控画面，但重）；VR（完全掌控视听，但会晕）；单一感官设备（把一件事做好，但小众）。
- **共同问题**：
  - 隐私（旁人和眼动数据）
  - 续航和重量的取舍
  - **依赖公司服务器**（Glass、Focals、HoloLens 2、Neosensory 都已终止）
  - 近视镜片的适配
  - 注意力分散

## 选择映射的设计原则

1. **替代还是增强？** 谁在用？信息是丢失了还是新增的？
2. **哪种映射？** 拓扑、参数还是符号，取决于来源信息的丰富程度和目标通道的容量。
3. **顺着跨通道对应关系设计**：高 ↔ 高音、亮 ↔ 响，这样学得更快。
4. **闭合回路**：低延迟；让用户能移动传感器去主动探索。
5. **匹配带宽，避免遮蔽**：只保留任务需要的信息，不要占用用户仍然依赖的感官。

## 课堂项目

**A. 设计一个映射**：在矩阵里选一格 → 选映射类型 → 定义编码（如倾斜 → 振动强度）→ 做原型（Grove IMU → Arduino/ESP32 → 马达或声音；用 Processing 测试）→ **蒙眼测试**（比较戴与不戴设备时的准确率和用时）。

- 替代的点子：躯干倾斜 → 倾斜一侧振动（平衡腰带）。
- 增强的点子：指南针方向 → 振动或音调（迷你版 feelSpace）。

**B. 做一个康复游戏**：

1. **感知**：IMU 戴在手腕或躯干上 → 倾斜角
2. **映射**：倾斜角 × **增益** → Processing 中的光标（增益 > 1 放大小动作）
3. **游戏**：去够目标；目标大小和距离决定难度
4. **自适应**：命中率高于 80% → 变难；低于 50% → 变易
5. **记录**：把重复次数、用时和成功率存成 CSV，画出进度曲线

- 测试：比较增益 1 和增益 2 下的重复次数、成功率和主观费力程度。
- 反馈方式：视觉分数、声音（音高 = 倾斜角），或命中目标时振动。
